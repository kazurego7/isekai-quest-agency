== ドメイン設計（概要）

* ロール: Requester / Receptionist / Adventurer / Appraiser
* 主なエンティティ:
  ** 依頼（Request）
  ** クエスト（Quest）
  ** 完了報告（CompletionReport）
  ** 素材納品（MaterialSubmission）
  ** 鑑定（Appraisal）
  ** 買い取り（Purchase）
* 状態遷移（暫定）:
  ** 依頼: 新規 → 確認済み → クエスト化
  ** クエスト: 募集中 → 受注済み → 完了報告済み → 達成確認済み
  ** 素材納品: 申請済み → 鑑定済み → 買い取り済み

== 画面/機能マッピング

* ロールごとの操作権限（想定）:
  ** Requester: 依頼の作成/閲覧、自分の依頼の閲覧
